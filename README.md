# Evaluación REBA · Herraidea

Proyecto independiente de la presentación original de ergonomía. Contenido integrado a partir de Practica_REBA_Herraidea_FINAL.docx.

Incluye portada, guía del método, observación, foto y video de pulido, puntuaciones y propuestas. La fotografía del DOCX se excluyó por indicación del usuario. Se presenta el escenario del material audiovisual: A 3, B 4, C 3, REBA 5; requiere confirmar el modificador de muñeca, carga, agarre y exposición estática y repetitiva. No constituye una medición validada automáticamente. La guía PDF original se conserva para consulta; las celdas del caso se contrastaron con Ergonautas.

Sitio estático sin dependencias. Para una vista local: `python3 -m http.server 4174` desde esta carpeta.
